# 🏆 Application de Gestion de Tournoi

Cette application web permet de gérer facilement des tournois via une interface intuitive. 
Elle est développée avec **Flask (Python)** et utilise **HTML**, **CSS** et **JavaScript** pour l’interface utilisateur.

## 🚀 Fonctionnalités principales

- Création, gestion et suivi de tournois
- Interface web accessible depuis un navigateur
- Fichier `config.txt` modifiable pour ajuster certains paramètres
- Application directement exécutable via `app.exe`

## 🛠️ Technologies utilisées

- **Python** (Flask)
- **HTML / CSS / JavaScript**
- **Exécutable Windows (.exe)** via PyInstaller ou équivalent

## 📦 Installation et utilisation

1. Télécharger le projet (ou cloner le dépôt)
2. Lancer simplement le fichier `build/exe.win-amd64-3.12/app.exe`
3. Ouvrir un navigateur à l’adresse indiquée dans la console (exemple : `http://127.0.0.1:5000`)
4. Pour en savoir plus, consulter le guide utilisateur 👉 [https://drive.google.com/file/d/1783g-4pfFbJqPwNvsnTexHVT6EBGlQXW/view]

## ⚙️ Personnalisation

Le fichier `config.txt` situé à la racine du app.exe permet de modifier certains paramètres de l’application.
